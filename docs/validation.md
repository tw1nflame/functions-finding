# Проверка обобщения на независимые эксперименты

## Разбиение до обучения

Наблюдения одного независимого эксперимента не могут попадать в разные части.
Единица разделения задаётся `group_column`. Если несколько организмов наблюдаются
в одном эксперименте, их ID передаются через `trajectory_column`, а группировка
для проверки остаётся по общему эксперименту.

По умолчанию `test_size=0.2`, `validation_size=0.2`, `random_state=42`.
Сначала `GroupShuffleSplit` отделяет test, затем из оставшихся групп выделяется
validation с долей `validation_size/(1-test_size)`. Доли относятся к группам, не
строкам. Из-за округления вверх фактические доли могут отличаться от заданных.
Слишком маленький набор групп даёт понятный отказ. `test_size=0` оставляет только
train/validation; тогда отдельная итоговая тестовая оценка отсутствует.

Для заранее подготовленного разбиения добавьте столбец с точными строками
`train`, `validation`, `test` и передайте `split_column`. Train и validation
обязательны, test опционален. Все строки одного независимого эксперимента должны
иметь одинаковую метку. Параметры случайных долей при таком протоколе не используются.

```python
result = model.fit(
    df,
    time_column="time",
    target_column="response",
    group_column="experiment_id",
    trajectory_column="organism_id",
    condition_columns=["temperature", "pH"],
    split_column="partition",
)
print(result.split_protocol.experiments)
```

Временные коэффициенты, нормировка условий, модели коэффициентов и их начальные
приближения используют только train. Все комбинации получают одно и то же разбиение.
Validation используется для выбора комбинации; test — только после окончательного
выбора. Коэффициенты validation/test-траекторий вообще не подбираются.

## Что измеряют отчёты

| Отчёт | Предсказание | Значение |
|---|---|---|
| `train_curve_fit` | Отдельная подогнанная кривая каждой train-траектории | Насколько выбранная временная форма описывает известную траекторию. |
| `train_general` | Общая `f(t;g(z))` на train | Обучающая ошибка двухэтапной зависимости. |
| `validation` | Общая модель на новых группах | Критерий выбора вторичных моделей. |
| `test` | Уже выбранная общая модель на нетронутых группах | Отдельная итоговая оценка. |

Низкая ошибка индивидуальных train-кривых не означает хороший прогноз новых
экспериментов: второй этап может плохо объяснять коэффициенты через условия.
`parameter_metrics` сравнивает прогнозы с train-оценками коэффициентов и является
вспомогательной диагностикой, а не критерием выбора и не независимой оценкой.

Для семейства с начальным состоянием `y0` берётся из первого измерения новой
траектории или передаётся отдельно. Это условный прогноз при известном начале.
Начальные наблюдения исключаются из **всех** агрегированных оценок качества,
включая train: модель не получает бонус за возвращение переданного ей значения.

## Два способа агрегации

Каждый отчёт содержит оба варианта:

- `observation`: обычные MAE, RMSE, R² по всем оцениваемым строкам; длинный
  эксперимент имеет больший вес.
- `experiment`: для каждого независимого эксперимента вычисляются MAE, RMSE, R²
  по всем его траекториям; затем каждая метрика усредняется по экспериментам.
  Macro RMSE здесь — **среднее RMSE**, а не корень среднего MSE.

`aggregation="experiment"` — критерий выбора по умолчанию. Можно выбрать
`"observation"`. Если в независимом эксперименте есть несколько траекторий,
сначала объединяются его наблюдения; одинаковый вес имеют эксперименты, а не
каждая отдельная траектория.

Для R² используется конвенция scikit-learn: на постоянной цели 1 при точном
совпадении, иначе 0. Для одной оцениваемой точки R² равен NaN; он сохраняется
таковым и при усреднении, RMSE остаётся определённым. Выбор производится по RMSE.

## Неудачные траектории и покрытие

Все train-попытки остаются в `experiment_parameters` и `train_fits`. Неустойчивые
коэффициенты не используются для второго этапа. Сводка сообщает число исключённых
траекторий; если пригодных данных или независимых групп недостаточно, результат
имеет `success=False` с причинами в таблицах.

Комбинация допускается к выбору **только если смогла предсказать все validation-
траектории**. Пропущенные значения или отказ прогноза одной траектории не позволяют
показать хорошую ошибку на оставшемся удобном подмножестве. Частичные метрики
могут сохраняться для диагностики, но `complete=False`, а `validation_score=inf`.

Отказ на test не меняет выбор модели. В `evaluations["test"].failures` сохраняются
причины, `metrics["test"]["complete"]` равен False и добавляется предупреждение
в результат. Частичные тестовые метрики нельзя выдавать за оценку полного test.
Подробные прогнозы содержат исходную позицию строки, experiment/trajectory ID,
время, факт, прогноз и признак `scored`.

## Условия нового прогноза

`result.prediction_scenarios(conditions)` различает:

- `seen_conditions`: сочетание факторов уже встречалось в пригодных train-данных,
  но прогнозируется новая траектория.
- `interpolation`: новое сочетание внутри диапазонов каждого фактора.
- `extrapolation`: хотя бы один фактор вышел за обучающий диапазон.

Диапазоны вычисляются только по траекториям, реально использованным для обучения
моделей коэффициентов. При экстраполяции `predict`/`predict_parameters` выдают
`ExtrapolationWarning`. Если выход намеренный, можно передать `warn_extrapolation=False`.
Диапазоны не расширяются при последующих прогнозах.

Проверка диапазонов — прямоугольная область по координатам, **не** анализ выпуклой
оболочки и плотности данных. Новая комбинация внутри этих диапазонов всё ещё может
быть далеко от исследованных сочетаний. Надёжность экстраполяции по времени отдельно
не оценивается. Если нужно проверить только новые сочетания условий, задайте split
заранее: случайное разделение независимых групп само по себе не разделяет уникальные
сочетания факторов.

## Проверки от утечек

Автоматические тесты проверяют, что:

- вызовы временного fitting происходят только для train;
- изменение validation-откликов не меняет train-коэффициенты;
- изменение test-откликов не меняет формулы, выбор и validation-ошибки;
- связанные траектории остаются в одной части, а явное нарушение отклоняется;
- повторные траектории не увеличивают число независимых экспериментов для сложной модели;
- ошибка общей кривой определяет выбор даже при противоположном ранжировании ошибок параметров;
- начальные точки не входят в оценочную метрику.
