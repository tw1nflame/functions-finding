# Как подбираются коэффициенты

В библиотеке разделены три решения: оценка чисел внутри заданной формулы, выбор
временного семейства и выбор зависимостей его коэффициентов от условий.

## 1. Фиксированное семейство

Для наблюдений $(t_j,y_j)$ выбирается формула $F(t;\boldsymbol\theta)$.
Например, логистика имеет четыре коэффициента:

$$
F(t;c,L,k,x_0)=c+\frac{L}{1+\exp[-k(t-x_0)]}.
$$

`fit_family` ищет параметры, минимизирующие сумму квадратов остатков:

$$
\widehat{\boldsymbol\theta}
=\underset{\boldsymbol\theta}{\operatorname{argmin}}
\sum_j\bigl[F(t_j;\boldsymbol\theta)-y_j\bigr]^2.
$$

Все наблюдения внутри одной кривой имеют одинаковый вес. Выбросы не удаляются;
robust loss и доверительные интервалы текущим API не предоставляются.

## 2. Линейный и нелинейный подбор

**Полиномы линейны по коэффициентам.** Для $a_0+a_1t+a_2t^2$ строится матрица
с колонками $1,t,t^2$, затем вызывается `numpy.linalg.lstsq` с проверкой ранга.
Время центрируется и масштабируется; результат переводится в исходную координату.
Стартовые приближения для такого решения не нужны.

**Остальные встроенные семейства:** `scipy.optimize.least_squares`,
`method="trf"`, `x_scale="jac"`, ограничения семейства. Оптимизатор оценивает
чувствительность остатков к параметрам численным якобианом и выбирает шаг внутри
области доверия. Реальное улучшение ошибки определяет изменение этой области.

Остатки делятся на один общий масштаб, вычисленный по обучающим $y$. Это улучшает
численное поведение и не меняет математического минимума суммы квадратов.
Допуски `ftol`, `xtol`, `gtol` равны $10^{-10}$; по умолчанию `max_nfev=2000` на старт.

## 3. Несколько начальных приближений

Каждое семейство строит детерминированные старты только по train. Для логистики
используются минимум и размах $y$, три оценки крутизны и три положения центра.
Всего девять стартов. Общая настройка `max_starts=12` ограничивает список,
но не добавляет новые старты, если семейство предоставляет меньше.

Каждый старт оптимизируется независимо. Из **сошедшихся** решений выбирается
минимальная обучающая ошибка. Если все старты неуспешны, возвращается
`FitResult(success=False)` с диагностикой. Глобальный минимум не гарантируется.

## 4. Сравнение временных семейств

`ModelSelector` создаёт одно разбиение для всех кандидатов. Коэффициенты и начальные
приближения определяются только по train; готовые формулы оцениваются на validation.

Пусть $R_*$ — минимальная validation RMSE. Допустимыми считаются модели с ошибкой
не выше $R_*(1+\varepsilon_r)+\varepsilon_a$. Из них выбирается меньшее число
параметров, затем меньшая ошибка, затем исходный порядок кандидатов.
По умолчанию относительный допуск $\varepsilon_r=0.01$.

Validation используется для выбора: её метрика не является независимым final test.
Автоматического refit на всех точках после выбора нет.

## 5. Параметризация через условия

В эксперименте $i$ условия $\mathbf z_i=(u_i,v_i)$ постоянны, а время меняется.
Сначала по train-кривым получаются оценки $\widehat\theta_{ik}$.
Затем для каждого временного параметра строится зависимость, например:

$$
\theta_k(u,v)=a_k+b_ku+c_kv,
$$

или полная квадратичная модель:

$$
\theta_k(u,v)=a_k+b_ku+c_kv+d_ku^2+e_kuv+f_kv^2.
$$

Коэффициенты этих зависимостей оцениваются взвешенными наименьшими квадратами
через sklearn. Суммарный вес траекторий одного независимого эксперимента равен единице.
Для параметров с преобразованием `log` регрессия оценивает $\log\theta_k$,
а прогноз возвращается через экспоненту.

В Auto проверяются сочетания моделей коэффициентов. Каждое сочетание подставляется
в $F$, после чего оценивается **ошибка исходных наблюдений $y$ на validation**.
По умолчанию выбирается средняя по независимым экспериментам RMSE, с предпочтением
меньшего общего числа коэффициентов при близком качестве.
Test оценивается после выбора и не участвует в нём.

```{important}
Это последовательная двухэтапная оценка. Совместной финальной оптимизации всей
поверхности по исходным наблюдениям нет. Неопределённость промежуточных параметров
не переносится на второй этап как статистическая оценка погрешности.
```

## 6. Проверка идентифицируемости

Хорошая кривая может иметь нестабильные коэффициенты: изменение одного параметра
компенсируется другим. Диагностика использует ранг и число обусловленности якобиана
после нормировки его столбцов. `fit_family` сохраняет предупреждение о недостаточном
ранге; второй этап исключает такие оценки и оценки с condition выше порога
`condition_threshold` (по умолчанию $10^8$).

Для линейной зависимости от двух факторов нужны минимум три сочетания $(u,v)$,
не лежащие на одной прямой; для полной квадратичной — минимум шесть точек
с полноранговой матрицей признаков. Это лишь алгебраический минимум. Нужны также
независимые повторы и отдельные данные для validation/test. Реализация дополнительно
проверяет достаточное число независимых train-групп относительно сложности модели.
