# Сборка документации

Документация использует Sphinx, тему Furo и MyST для Markdown.
API извлекается из актуальных сигнатур и docstring исходного кода через autodoc;
NumPy-style docstring обрабатываются Napoleon.

## Собрать HTML

Из корня проекта:

```console
uv sync --extra docs
uv run --extra docs python -m sphinx -W --keep-going -b html docs docs/_build/html
```

Альтернативная установка в существующее окружение:

```console
python -m pip install -e ".[docs]"
python -m sphinx -W --keep-going -b html docs docs/_build/html
```

`-W` превращает предупреждения в ошибку сборки. Файл результата —
`docs/_build/html/index.html`. Его можно открыть напрямую в браузере.

В этом окружении основной PyPI был недоступен, поэтому в `pyproject.toml` и `uv.lock`
зафиксировано зеркало PyPI Tsinghua. Если нужен основной индекс, используйте
`uv sync --extra docs --default-index https://pypi.org/simple`.

Для просмотра через локальный сервер:

```console
python -m http.server 8000 --bind 127.0.0.1 --directory docs/_build/html
```

Затем откройте `http://127.0.0.1:8000`. Сервер останавливается через Ctrl+C.
Статический каталог `docs/_build/html` можно разместить на обычном HTML-хостинге;
сервер Python нужен только для локального просмотра.

## Проверить примеры

```console
uv run --extra docs python -m sphinx -W --keep-going -b doctest docs docs/_build/doctest
```

В [проверяемых примерах](verified_examples.rst) находятся короткие smoke-примеры
публичного API. Они запускаются doctest-сборкой и не требуют сети или реального Excel.
Длительные исследовательские ноутбуки в сборке документации не выполняются.

## Структура исходников

- `index.md` задаёт главную страницу и порядок навигации.
- Markdown-руководства хранятся непосредственно в `docs/`.
- `api/*.rst` содержат autodoc-директивы и пояснения API.
- `_static/` содержит стили и favicon. Основной интерфейс предоставляет Furo.
- `conf.py` задаёт версию из пакета, русский поиск и математическую разметку.
- `_build/` — генерируемый результат, исключённый из системы контроля версий.

В существующих Markdown-страницах поддержана запись формул `\[` … `\]`:
при чтении Sphinx она переводится в блочный синтаксис MyST. В новых страницах
можно использовать `$$` или директиву `{math}`.
Формулы в браузере отображает MathJax, который по умолчанию загружается с CDN;
для их отрисовки требуется интернет. Навигация, поиск, код и текст входят в локальную
сборку. Ссылки на загружаемые `.ipynb` оформляются ролью `{download}`, чтобы Sphinx
скопировал файл внутрь HTML-каталога.

Не добавляйте в справочник несуществующие методы. Для новых публичных объектов
добавляйте autodoc-директиву и небольшой проверяемый пример.
